# NT Connect — 3-minute live demonstration

**Core message:** Find gaps → explain their context → explore interventions → keep planning information available offline.

1. **Opening (15s):** “Remote Australia’s connectivity information comes from separate datasets. NT Connect brings source-derived information together in one readable, offline-first explorer.”
2. **Discover (30s):** Search for a NT location; select a marker; show 188 source locations and the 48 separately listed Black Spot projects. Use filters or the ranking.
3. **Understand (45s):** Show the selected profile, Gap Index contributors, mobile flag limitation, supplied NBN fixed-line-only context and historical cyclone context. Mention data-completeness percentage is not a network-accuracy rating.
4. **Action (40s):** Open ‘Possible action plan’. Show how observations trigger different *investigations*, not approved investments; highlight essential-service continuity and community consultation.
5. **Resilience (30s):** Open directory listings and emergency reference, then download the readable HTML community pack.
6. **Offline moment (20s):** In a previously cached browser tab, toggle DevTools Network → Offline and refresh. Show the map and profile remain available; separately open the HTML pack.

**Question judges may ask:** “How do you know these locations have poor connectivity?” Answer: “We do not claim measured signal quality. The dataset contains infrastructure/proximity flags; the index prioritises further investigation alongside demographic, remoteness, programme and resilience context.”

**Other key answers:** NBN is fixed-line-only; cyclone is historical-relative; essential-service listings are a pilot directory, not real-time availability; offline emergency contacts are reference information, not live alerts or calls.
